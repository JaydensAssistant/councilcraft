# CouncilCraft

Custom gameplay mod for the CouncilCraft vanilla+ pack. Minecraft **1.20.1**, Fabric Loader **0.19.5**, Fabric API **0.92.12+1.20.1**, Java **17**. The mod id is `councilcraft`. It is required on the client and on the server.

Jayden builds the jar from this source. The only command is:

```sh
./gradlew build
```

That compiles against the locked pack mods (fetched from Modrinth Maven), runs the unit tests, and writes `build/libs/councilcraft-<version>.jar`. Nothing is published. Do not commit that jar. The Gradle wrapper jar is the only binary in the repo; it is the build tool, not a mod.

You need JDK 17 or newer on the path (Gradle can run on 21; the class files are still Java 17) and a network connection the first time, so Gradle can download Minecraft, Yarn, Fabric, and the hooked mods.

## What this repo is

One mod, four review slices. Each slice is a pull request. Numbers such as S226 refer to `SPEC.md`. A line tagged SUPERSEDED is not what the code does; the newer entry named in the tag is. Every constant is in `CouncilCraftRules`.

Hooks 19–21 and the POST-MVP list in `councilcraft-hooks.md` are not implemented. Hook 17 (Regions Unexplored planks in the Small Ships dockyard) is not implemented either: Stage 1 already checked that every dockyard recipe uses `#minecraft:planks` and that Regions Unexplored planks are in that tag, so no mixin is required.

Mixins into other mods are required (`defaultRequire: 1`). A renamed target crashes startup and names the mixin in the log. `CouncilCraftMixinPlugin` does the same if Horseshoes, Mutant Monsters, Paragliders, Supplementaries, Create, Numismatics, Pehkui or Create Enchantment Industry is not installed. Create's toolbox class, Create's basin class, Numismatics' coin enum, the Blaze Forger and the printer are checked by name when the mod starts. Create itself is a compile-only dependency (not packed into this jar) so Loom can remap inherited Minecraft calls such as `BasinBlockEntity.getWorld`. A stub for that class left the yarn name in the remapped jar, and every basin recipe crashed. `checkUnmappedYarn` fails the build if a yarn-named Minecraft member reference to a class outside this mod survives in the remapped jar. The Blaze Forger and printer mixins stay pseudo because Create Enchantment Industry is not a compile dependency.

The Reborn hover text is client-only. `councilcraft.client.mixins.json` is not loaded on a dedicated server. The mixin is `mixin/client/RebornEffectTooltipMixin.java`. `CouncilCraftClient` registers the clock packet, and `respawn/RebornClient.java` turns it into the live line. Those three are the client surface for this hook.

## Textures

The netherite horseshoe texture is a hand recolor of Horseshoes 1.0.3 `assets/horseshoes/textures/item/diamond_horseshoes.png` (HyperPigeon, MIT). The diamond blues were replaced with a dark netherite palette.

The Reborn effect icon (`textures/mob_effect/reborn.png`) is a placeholder. Minecraft's own effect icons are not redistributable, and none of the pack mods with a compatible licence ship an effect icon that can be recolored. The pixels were placed by hand. The top-left pixel is magenta (`#FF00FF`) so the placeholder is obvious in the texture. No AI-generated art.

The spur, bevel and sprocket molds are recolors of Create: Coins Arise 1.0.2 `spur_casting_mold.png`, `bevel_casting_mold.png` and `sprocket_casting_mold.png` (SnackBag.NET, JX_Snack, Kamilskii, Kszaczuch, LGPL-2.1). Coins Arise is not in the pack. The cog, crown and sun molds keep the sprocket mold's outline and shading, and the mark in the middle is new hand-placed pixels. The LGPL text ships in the jar as `META-INF/LICENSE-coins-arise-LGPL-2.1.txt`. Both notices are in `META-INF/councilcraft-texture-credits.txt`. No AI-generated art.

## How to test in a singleplayer world

Install this jar next to the pack mods. Create a creative world.

- **Riptide.** Enchant a trident with Riptide III, stand in rain or water, hold right click. The lunge should be clearly shorter than vanilla (about half). Riptide I and II are halved the same way. A dry trident still does not launch.
- **Depth Strider.** Wear Depth Strider III boots and swim. Note the speed. Then gain Dolphin's Grace (potion or a dolphin). Swim speed should match Grace alone, not the stacked Grace + Depth Strider sprint. Take the boots off: Grace alone is unchanged. Let Grace expire: Depth Strider alone is unchanged.
- **Paraglider.** Damage a paraglider on an anvil. A phantom membrane is a valid repair material. Leather still is, too. The 384 durability is the Paragliders config, not this mod.
- **Sacks.** Craft a Supplementaries sack. It does not fit in a bundle. It does not fit in a Create toolbox. (Supplementaries 1.20-3.1.44 already returns false here; the mixin keeps it that way.)
- **Gold horseshoes.** `/loot spawn ~ ~ ~ loot minecraft:chests/nether_bridge` and the four `minecraft:chests/bastion_*` tables. No gold horseshoes. Desert pyramid and end city loot can still roll iron or diamond horseshoes, not gold. Iron and diamond horseshoes elsewhere are unchanged.
- **Creepers.** Spawn `mutantmonsters:mutant_creeper` and `mutantmonsters:creeper_minion` and let them explode next to stone and next to a mob. The mob takes damage. The stone does not break. A vanilla creeper still breaks blocks while `mobGriefing` is true. The minion tracker's "destroys blocks" toggle cannot turn block damage back on.
- **Handshake.** Join this same world: you have the mod, so you get in. On a dedicated server, a client without the jar is disconnected with "This server requires the CouncilCraft mod. Install the CouncilCraft modpack." A client built from a different `mod_version` is disconnected with both version numbers. Both sentences are literal text, because that client is not running this mod. The disconnect is sent when login is about to accept the player, after every login query has been answered, so the client shows that sentence instead of "Connection reset by peer".
- **Horseshoes.** Put iron horseshoes on a horse and ride it at a one-block and a two-block ledge. Mounted, it steps up 2 blocks. Dismount, and it is back to one block, so a pen still holds it. Diamond steps 2 blocks (the value is 2.6). Netherite steps 3. Smith the netherite pair: netherite upgrade template, diamond horseshoes, netherite ingot. Toss the netherite pair in lava: the item survives. A fast horse (or one with a Speed potion) does not go past the cap: attribute movement of 0.44. A camel's step stays 1.5 while it is not wearing shoes. Camels, llamas and zebras are not in the Horseshoes "allowed to wear" tag, so they do not get the step bonus unless a datapack adds them. The speed cap still applies to them.
- **Toolbox.** Open a Create toolbox. A wrench, a shaft, an andesite casing, redstone, a torch and an arrow go in. A cobblestone, a plank and a sack do not. The tag files under `data/councilcraft/tags/items/` are the draft whitelist. A datapack can add an item by extending `councilcraft:toolbox_contents` or one of the four tags it includes. Every id in those tags exists in Create 6.0.8.1, Supplementaries 1.20-3.1.44, Farmer's Delight Refabricated 1.20.1-2.5.7, or vanilla 1.20.1. Create 6 has one white sail, one nixie tube, and no `create:rope` (the rope that goes in is `supplementaries:rope`).
- **Coins.** Put a numismatics spur and a sun in a bank or vendor, or read the value tooltip. They should price as 1 and 100, not 1 and 4096. The other four are 5, 10, 20 and 50.
- **Molds.** The six molds are in the Ingredients creative tab (1 Dia Mold through 100 Dia Mold). There is no crafting recipe for them. Give yourself one with `/give @p councilcraft:cog_mold`. Drop it in lava, on a cactus, and in the void: it comes back. Die with it in your inventory: it is in the death pile, and another player can pick it up. It does not vanish after five minutes.
- **Minting.** Mechanical press on a basin. One diamond plus the 1 Dia mold presses one spur and returns the mold. Five, ten and twenty diamonds do the same for the 5, 10 and 20 molds. The 50 mold takes 5 diamond blocks and 5 diamonds and returns 50 crowns plus the mold. The 100 mold takes 11 diamond blocks and 1 diamond and returns 100 suns plus the mold. One netherite ingot plus the 20 mold returns 20 cogs. Five netherite ingots plus the 100 mold returns 100 suns. Emeralds do nothing. Put ten diamonds in first and the 10 Dia mold second: the press mints sprockets instead of a diamond block. Same for twenty diamonds and the 20 Dia mold. If the press had already started the diamond-block craft, that cycle finishes with nothing made and the next one mints.
- **Patrols.** Wait for a night patrol, or summon several with a command that runs the patrol spawner. About one patrol in four has an evoker standing one block east of the captain. That evoker follows the patrol instead of standing still. The pillagers are still there. Illager Invasion may have already swapped some of them for marauders; the evoker is added on top, not instead of a member.
- **Reborn.** Die in survival. There is no boss bar and no chat line. The inventory effect list shows Reborn with a countdown. Hover it. The tooltip is three lines: "Incrementally return to adult stats over one real life day, on or offline." then "60% size, 85% speed, 70% strength, 60% HP" then "Now:" with the same four at the start. You are about 60% size, on 6 hearts, and you move and hit softer. Drink milk, use a totem, or run `/effect clear`: the icon comes back on the next tick and the penalties stay. Creative inventory shows the same hover. Log out and back in before the day is up: the countdown has kept moving. Die again: the 24 hours start over. An operator runs `/councilcraft reborn clear` (or with a player name) to end it early. A player who is not an operator cannot.
- **Blaze Forger.** Merge two Sharpness V books. The result stays at V. The same for Power, Protection and Blast Protection. Merge a Sharpness V book into an item that already has Sharpness VI: it can stay at VI, one above the vanilla max. Efficiency cannot go above its vanilla max, even if one input is already above it.
- **Printed copies.** Print an enchanted book. The copy's tooltip has a grey "Printed Copy" line. The printer will not take that copy as a template, at the start of a job or at the end. Put the printed book in an anvil's sacrifice slot on a normal tool: the tool is not marked. Put a printed tool in the base slot and repair it: the result stays printed. Smithing a printed item keeps the mark. Extract an enchant from a printed item in the Blaze Forger: the template that receives the enchant is marked.

`./gradlew test` covers the respawn curve, the tooltip percents, the client clock math, and the forger clamp, along with the older arithmetic (half riptide, depth-strider level, which loot entries survive, version match). It does not launch a world. The checks above need one.
