# CouncilCraft

Custom gameplay mod for the CouncilCraft vanilla+ pack. Minecraft **1.20.1**, Fabric Loader **0.19.5**, Fabric API **0.92.12+1.20.1**, Java **17**. The mod id is `councilcraft`. It is required on the client and on the server.

Jayden builds the jar from this source. The only command is:

```sh
./gradlew build
```

That compiles against the locked pack mods (fetched from Modrinth Maven), runs the unit tests, and writes `build/libs/councilcraft-<version>.jar`. Nothing is published. Do not commit that jar. The Gradle wrapper jar is the only binary in the repo; it is the build tool, not a mod.

You need JDK 17 or newer on the path (Gradle can run on 21; the class files are still Java 17) and a network connection the first time, so Gradle can download Minecraft, Yarn, Fabric, and the hooked mods.

## What this repo is

One mod, four review slices. Each slice is a pull request. Numbers such as S226 refer to `SPEC.md`. A line tagged SUPERSEDED is not what the code does; the newer entry named in the tag is. Every constant is in `CouncilCraftRules`.

Hooks 19–21 and the POST-MVP list in `councilcraft-hooks.md` are not implemented. Hook 17 (Regions Unexplored planks in the Small Ships dockyard) is not implemented either: Stage 1 already checked that every dockyard recipe uses `#minecraft:planks` and that Regions Unexplored planks are in that tag, so no mixin is required.

Inventorio is the one optional mod (`suggests`, compile-only). `CouncilCraftMixinPlugin` skips `SackEncumbranceMixin` unless both Supplementaries and Inventorio are loaded, so the jar still starts without Inventorio. With Inventorio installed, the mixin is required like the others, and `CouncilCraft` loads its Supplementaries target (`ItemsUtilImpl`) at startup, so a renamed method crashes at boot rather than on the first sack tick.

Mixins into other mods are required (`defaultRequire: 1`). A renamed target crashes startup and names the mixin in the log. `CouncilCraftMixinPlugin` does the same if Horseshoes, Mutant Monsters, Paragliders, Supplementaries, Create, Numismatics, Pehkui or Create Enchantment Industry is not installed. Create's toolbox class, Create's basin class, Numismatics' coin enum, the Blaze Forger and the printer are checked by name when the mod starts. Create itself is a compile-only dependency (not packed into this jar) so Loom can remap inherited Minecraft calls such as `BasinBlockEntity.getWorld`. A stub for that class left the yarn name in the remapped jar, and every basin recipe crashed. `checkUnmappedYarn` fails the build if a yarn-named Minecraft member reference to a class outside this mod survives in the remapped jar. The Blaze Forger and printer mixins stay pseudo because Create Enchantment Industry is not a compile dependency.

The Reborn hover is client-only. `councilcraft.client.mixins.json` is not loaded on a dedicated server. Jayden, these are the client files for this hook:

- `mixin/client/RebornEffectTooltipMixin.java` replaces the vanilla effect tooltip with two lines. It does not target EMI's mixin. When EMI is drawing effects along the top, the single-effect bar (which has no tooltip) gets the two lines at the end of the vanilla draw.
- `mixin/client/RebornTooltipDrawMixin.java` replaces the list passed to `DrawContext.drawTooltip`, which is the method both vanilla and EMI use for the multi-effect hover.
- `respawn/RebornTooltip.java` is the two-line text and the single-bar position. The position follows EMI 1.1.24's centered layout, and it draws only when EMI's effect location is `TOP`.
- `respawn/RebornEmi.java` reads that location by reflection. EMI is not a compile dependency.
- `mixin/client/HandledScreenAccess.java` reads the inventory x, y and width for that single bar.
- `respawn/RebornClient.java` keeps the accrued active minutes from the server. It does not add wall-clock time. A finished packet clears a local Reborn icon. It does not guess other effects by duration. The clock payload is unchanged; the two longs are minutes now.

`CouncilCraftClient` registers that packet. The effect's own duration is the remaining active time, and it counts down like any other effect. Jayden, the client change this round is the removal of `RebornDurationMixin` from the common mixin set, so the client no longer freezes that countdown. `RebornKeepaliveMixin` is also common: it stops vanilla's every-600-tick effect resend for Reborn only, which was a packet every tick while the duration was frozen on a multiple of 600. The tooltip mixins and the lang file are unchanged. The server writes the duration again at each five-minute boundary, and on respawn: five minutes less when the window counted, the same remaining time when it did not (the countdown snaps back up). While minutes remain, that write is at least one window plus a short pad, so the icon cannot expire between writes. JOIN does not send the effect. There are no Reborn particles.

## Textures

The netherite horseshoe texture is a hand recolor of Horseshoes 1.0.3 `assets/horseshoes/textures/item/diamond_horseshoes.png` (HyperPigeon, MIT). The diamond blues were replaced with a dark netherite palette.

The Reborn effect icon (`textures/mob_effect/reborn.png`) is original CouncilCraft art: an 18×18 baby face, hand-pixeled for this mod, with no third-party source. Vanilla loads that one texture for both the HUD icon and the inventory effect icon. No AI-generated art.

The spur, bevel and sprocket molds are recolors of Create: Coins Arise 1.0.2 `spur_casting_mold.png`, `bevel_casting_mold.png` and `sprocket_casting_mold.png` (SnackBag.NET, JX_Snack, Kamilskii, Kszaczuch, LGPL-2.1). Coins Arise is not in the pack. The cog, crown and sun molds keep the sprocket mold's outline and shading, and the mark in the middle is new hand-placed pixels. The LGPL text ships in the jar as `META-INF/LICENSE-coins-arise-LGPL-2.1.txt`. Both notices are in `META-INF/councilcraft-texture-credits.txt`. No AI-generated art.

## How to test in a singleplayer world

Install this jar next to the pack mods. Create a creative world.

- **Riptide.** Enchant a trident with Riptide III, stand in rain or water, hold right click. The lunge should be clearly shorter than vanilla (about half). Riptide I and II are halved the same way. A dry trident still does not launch.
- **Depth Strider.** Wear Depth Strider III boots and swim. Note the speed. Then gain Dolphin's Grace (potion or a dolphin). Swim speed should match Grace alone, not the stacked Grace + Depth Strider sprint. Take the boots off: Grace alone is unchanged. Let Grace expire: Depth Strider alone is unchanged.
- **Paraglider.** Damage a paraglider on an anvil. A phantom membrane is a valid repair material. Leather still is, too. The 384 durability is the Paragliders config, not this mod.
- **Sacks.** Craft a Supplementaries sack. It does not fit in a bundle. It does not fit in a Create toolbox. (Supplementaries 1.20-3.1.44 already returns false here; the mixin keeps it that way.)
- **Gold horseshoes.** `/loot spawn ~ ~ ~ loot minecraft:chests/nether_bridge` and the four `minecraft:chests/bastion_*` tables. No gold horseshoes. Desert pyramid and end city loot can still roll iron or diamond horseshoes, not gold. Iron and diamond horseshoes elsewhere are unchanged.
- **Creepers.** Spawn `mutantmonsters:mutant_creeper` and `mutantmonsters:creeper_minion` and let them explode next to stone and next to a mob. The mob takes damage. The stone does not break. A vanilla creeper still breaks blocks while `mobGriefing` is true. The minion tracker's "destroys blocks" toggle cannot turn block damage back on.
- **Handshake.** Join this same world: you have the mod, so you get in. On a dedicated server, a client without the jar is disconnected with "This server requires the CouncilCraft mod. Install the CouncilCraft modpack." A client built from a different `mod_version` is disconnected with both version numbers. Both sentences are literal text, because that client is not running this mod. The disconnect is sent when login is about to accept the player, after every login query has been answered, so the client shows that sentence instead of "Connection reset by peer".
- **Horseshoes.** Put iron horseshoes on a horse and ride it at a one-block and a two-block ledge. Mounted, it steps up 2 blocks. Dismount, and it is back to one block, so a pen still holds it. Diamond steps 2 blocks (the value is 2.6). Netherite steps 3. Smith the netherite pair: netherite upgrade template, diamond horseshoes, netherite ingot. Toss the netherite pair in lava: the item survives. A fast horse (or one with a Speed potion) does not go past the cap: attribute movement of 0.44. A camel's step stays 1.5 while it is not wearing shoes. Camels, llamas and zebras are not in the Horseshoes "allowed to wear" tag, so they do not get the step bonus unless a datapack adds them. The speed cap still applies to them.
- **Sacks in Inventorio slots (0.4.1).** Supplementaries checks every 27 ticks, on the server, and the effect lasts 10 seconds, so give it a few seconds after each change. Its `sack_increment` config (default 2) is still the free count; more than that is Overencumbered, one level higher per extra multiple. Fill some sacks (an empty sack weighs nothing). Survival mode; creative and spectator are never slowed.
  - Wear leggings with Deep Pockets III. Put 3 filled sacks only in the Deep Pockets rows, nothing in the main inventory: Overencumbered appears. Then 5: the level goes up. Move the same 3 or 5 into the main inventory instead: the same level.
  - Put 3 filled sacks only in the utility belt (no Deep Pockets needed for the first 4 slots): Overencumbered appears, the same level as 3 in the main inventory. 2 sacks split one in the belt and one in the main inventory: no slowness.
  - Split 3 sacks across main inventory, Deep Pockets and utility belt: the level is the one for 3, not more (nothing counted twice).
  - With the sacks in the Deep Pockets rows, take the leggings off. The Deep Pockets items drop on the ground. The slowness wears off within 10 seconds and does not come back.
  - Sacks still do not fit in a bundle or a Create toolbox (see Sacks and Toolbox below), and the toolbox whitelist is unchanged.
- **Toolbox.** Open a Create toolbox. A wrench, a shaft, an andesite casing, redstone, a torch and an arrow go in. A cobblestone, a plank and a sack do not. The tag files under `data/councilcraft/tags/items/` are the draft whitelist. A datapack can add an item by extending `councilcraft:toolbox_contents` or one of the four tags it includes. Every id in those tags exists in Create 6.0.8.1, Supplementaries 1.20-3.1.44, Farmer's Delight Refabricated 1.20.1-2.5.7, or vanilla 1.20.1. Create 6 has one white sail, one nixie tube, and no `create:rope` (the rope that goes in is `supplementaries:rope`).
- **Coins.** Put a numismatics spur and a sun in a bank or vendor, or read the value tooltip. They should price as 1 and 100, not 1 and 4096. The other four are 5, 10, 20 and 50.
- **Molds.** The six molds are in the Ingredients creative tab (1 Dia Mold through 100 Dia Mold). There is no crafting recipe for them. Give yourself one with `/give @p councilcraft:cog_mold`. Drop it in lava, on a cactus, and in the void: it comes back. Die with it in your inventory: it is in the death pile, and another player can pick it up. It does not vanish after five minutes.
- **Minting.** Mechanical press on a basin. One diamond plus the 1 Dia mold presses one spur and returns the mold. Five, ten and twenty diamonds do the same for the 5, 10 and 20 molds. The 50 mold takes 5 diamond blocks and 5 diamonds and returns 50 crowns plus the mold. The 100 mold takes 11 diamond blocks and 1 diamond and returns 100 suns plus the mold. One netherite ingot plus the 20 mold returns 20 cogs. Five netherite ingots plus the 100 mold returns 100 suns. Emeralds do nothing. Put ten diamonds in first and the 10 Dia mold second: the press mints sprockets instead of a diamond block. Same for twenty diamonds and the 20 Dia mold. If the press had already started the diamond-block craft, that cycle finishes with nothing made and the next one mints.
- **Patrols.** Wait for a night patrol, or summon several with a command that runs the patrol spawner. About one patrol in four has an evoker standing one block east of the captain. That evoker follows the patrol instead of standing still. The pillagers are still there. Illager Invasion may have already swapped some of them for marauders; the evoker is added on top, not instead of a member.
- **Reborn.** Die in survival and respawn. Recovery starts at that respawn, not at the moment of death. It takes 6 hours, 360 minutes, of active play. Standing still does not count, and logging out does not count. There is no boss bar and no chat line. The inventory effect list shows Reborn. The time on it is the active time still left, and it counts down smoothly. The server rewrites that time at each 5-minute boundary, and again on respawn: five minutes less when the window counted, the same remaining time when it did not, so an idle window snaps the timer back up. It does not send that packet every tick. Hover it. The tooltip is two lines: "Grows up after 6 hours of active play." and "Now:" with the live size, speed, strength and HP. At the start that second line is "Now: 60% size, 85% speed, 70% strength, 60% HP". There is no separate floor-stats line. You are about 60% size, on 6 hearts (12 HP), and you move and hit softer. Max health gains one hit point every 45 credited minutes: 13 HP at 45, 14 at 90, and 20 at 360. The HP percent follows that step, not a smooth line. There are no particles on the icon. The icon is the baby face, on the HUD and in the inventory list. Hunger drops faster at the start (1.5 times exhaustion) and eases back to normal with the other penalties. Sprinting, jumping, and mining are the drain; it is not a Hunger potion effect. A window counts only when, somewhere in those 5 minutes, you both looked around (at least 30 degrees, and at least 5 degrees of yaw and 5 of pitch, not a spin on one axis) and did something else: break or place a block, use a block or item, open a container or your inventory, attack, craft, trade, or click a menu. You also have to have walked, swum, sneaked, sprinted or jumped in the last 30 minutes. A minecart, boat, horse or train does not count. Falling, ice momentum, knockback, a bubble column, a piston, a water current and a teleport do not count either. Only a move the server accepts counts. The step and the jump the server expects shrink with the current size and speed, so a newly reborn player still counts, and a water current is taken off the packet before that comparison. Swimming straight up counts. A jump from a standstill counts when the last position packet was a rest, up to a second earlier. Chat, eating, and drinking do not count. The same action on one target is one held stream when each gap stays within 2 ticks of the gap before it, so an autoclicker alternating 4 and 5 ticks does not count. Twelve or more actions are a macro when their gaps sit within 3 ticks of each other or the gap standard deviation is 1.5 ticks or less. Those runs are ignored; another real action in the same window still counts. Irregular clicking still counts. Logging out throws away the unfinished window. The saved number is active minutes. An old save that still has the wall-clock key or the effect, and no minute count, starts this recovery at zero instead of leaving the effect stuck. With EMI's effects along the top, the same two lines are on that effect's own tooltip. One effect alone is a wide bar: the name and the time stay in the bar, and the hover is the two lines. If EMI is set to draw effects on the left or right, that top bar is not drawn. Drink milk, use a totem, or run `/effect clear`: the icon comes back on the next tick and the penalties stay. Log out and back in: the active minutes already earned are still there, and they did not move while you were offline. The join sends the accrued minutes and the attributes only. The effect icon follows on a later tick, after registry sync, so it stays Reborn. Die again: the 6 active hours start over. An operator runs `/councilcraft reborn clear` (or with a player name) to end it early, or `/councilcraft reborn status <player>` to see the active minutes credited and whether the last window counted. A player who is not an operator cannot.
- **Blaze Forger.** Super mode, Sharpness V in both slots. The item comes back unchanged, and the second book and the XP are still there. The same for Protection IV and IV. Merge a Sharpness V book into an item that already has Sharpness VI: it can stay at VI, one above the vanilla max. Efficiency cannot go above its vanilla max, even if one input is already above it.
- **Printed copies.** Print an enchanted book. The copy's tooltip has a grey "Printed Copy" line. The printer will not take that copy as a template, at the start of a job or at the end. Put the printed book in an anvil's sacrifice slot on a normal tool: the tool is not marked. Put a printed tool in the base slot and repair it: the result stays printed. Smithing a printed item keeps the mark. Extract an enchant from a printed item in the Blaze Forger: the template that receives the enchant is marked.

- **0.4.2 checks.** Feed a Reborn player a meal from a second client: block pose, crumbs at the target, Growth Spurt appears and the recovery speeds up. Pay a vendor 21 with a dollar: change is a half dollar, a quarter and 4 pennies. Glide: stamina shows in the XP bar. Press M with the atlas item in the inventory. Nameplates show over a mutant and a GeckoLib mob. With DH and Iris, look through a portal: no DH terrain drawn over the portal view.
`./gradlew test` covers the respawn curve, the hunger exhaustion curve, half-heart health steps (one hit point per 45 minutes, including the HP percent), the activity window (4/5 autoclicker, one-tick jitter, irregular clicks, 5 degrees per axis), the self-move check, that saved minutes do not catch up offline, a legacy save starting at zero, the two-line hover text, that joining does not send the effect, and the forger clamp, that the Inventorio sack mixin is skipped unless both mods are loaded, along with the older arithmetic (half riptide, depth-strider level, which loot entries survive, version match). It does not launch a world. The checks above need one. `./gradlew check` also rejects a yarn-named Minecraft member left in the remapped jar.
